# N-Queens Problem Solver

A Python implementation of the classic N-Queens problem using the backtracking algorithm, featuring a graphical chessboard and animated visualization.

## Features

* Graphical chessboard representation
* Animated backtracking visualization
* Adjustable animation speed
* Conflict detection and solution counting

## Requirements

* Python 3.x
* Tkinter (included with most standard Python installations)

## Usage

Run the standard solver:

```bash
python n_queens.py
```

Run the animated visualizer:

```bash
python n_queens_visualizer.py
```

## Technologies

Python · Tkinter · Backtracking Algorithm
